# 🚀 Alfido Tech Data Science Internship

This repository contains the projects completed as part of my **Data Science Internship at Alfido Tech**. The internship provided hands-on experience in data analysis, machine learning, data visualization, and deriving actionable insights from real-world datasets.

---

## 📌 Internship Projects

### 🍴 Task 1: Zomato Restaurant Data Analysis

**Objective:** Analyze restaurant data to identify trends in ratings, customer preferences, cuisines, pricing, and location-based performance.

#### Key Activities

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Cuisine and Rating Analysis
* Location-Based Insights
* Cost vs Rating Analysis
* Data Visualization
* Business Recommendations

#### Deliverables

* Jupyter Notebook
* Analysis Report (PDF)
* Visualizations and Insights

---

### 🏦 Task 2: Loan Approval Prediction

**Objective:** Build and evaluate machine learning models to predict loan approval decisions using applicant information.

#### Key Activities

* Data Cleaning and Feature Engineering
* Missing Value Handling
* Class Imbalance Handling using SMOTE
* Model Training and Evaluation
* Performance Comparison
* Business Interpretation of Results

#### Models Evaluated

* Logistic Regression
* Decision Tree
* Random Forest
* Gradient Boosting
* XGBoost
* LightGBM

#### Deliverables

* Jupyter Notebook
* Machine Learning Report (PDF)
* Model Evaluation Results

---

### 📸 Task 3: Instagram Engagement Analysis

**Objective:** Analyze Instagram engagement data to identify content performance trends and optimal social media strategies.

#### Key Activities

* Data Cleaning and Preprocessing
* Engagement Analysis
* Hashtag Performance Analysis
* Posting Schedule Analysis
* Content Performance Evaluation
* Strategy Development

#### Deliverables

* Jupyter Notebook
* Instagram Strategy Report (PDF)
* Engagement Analysis Visualizations
